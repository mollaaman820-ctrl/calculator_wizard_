# Kepler Scientific Calculator

A browser-based scientific calculator with interactive function graphing and symbolic/numeric calculus tools.

## Run

```sh
npm install
npm run dev
```

## Features

- Scientific arithmetic with degree/radian modes and keyboard input
- Multi-function interactive graphing with adjustable domain and derivative overlays
- Symbolic differentiation and indefinite integration, plus numerical definite integrals and root finding

Build with `npm run build`.
